## Proyectos

### Local AI Studio
Aplicación para ejecutar modelos de IA en el propio computador sin enviar datos a terceros. Incluye chat con Ollama, consultas sobre documentos propios mediante RAG y generación de imágenes con Stable Diffusion. Tiene pruebas, integración continua y verificación de secretos antes de cada commit.

https://github.com/Terminator2424/local-ai-studio

### Finzen
Aplicación de finanzas personales que funciona sin conexión. Registra los movimientos leyendo las notificaciones del teléfono. Está organizada como monorepo con la app móvil y los paquetes compartidos; el APK se compila con GitHub Actions.

https://github.com/Terminator2424/Finzen

### FacturaDIAN
Facturación electrónica con las reglas de la DIAN: IVA del 19 por ciento y ReteIVA del 15 por ciento. Arquitectura hexagonal sobre Quarkus, vistas con Qute, MySQL, reportes y facturas en PDF, con login por roles. Repositorio privado.

### Optimización de rutas
Optimización de rutas de visita a restaurantes reales de un dataset de Kaggle usando Hill Climbing. El recorrido pasó de 73.47 km a 33.33 km en 423 iteraciones, una mejora del 54.64 por ciento.

### Latinoamérica Comparte
Plataforma web con Spring Boot: controladores, DAOs, entidades, DTOs y una capa de seguridad con filtros. Integra el trabajo de varias asignaturas del semestre.
